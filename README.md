# Lógica de programación 01

Ejercicio de JavaScript para practicar entrada de datos, arreglos, validación y ciclos.

## Objetivo

Solicitar tres números separados por comas, ordenarlos de mayor a menor y mostrar el resultado en la consola.

## Conceptos practicados

- Variables y tipos de datos.
- `prompt()` y `alert()`.
- `split()` y `map()`.
- Validación con `some()`.
- Ordenamiento con `sort()`.
- Ciclo `while` y condicionales.

## Ejecución

Abre `ej1/logica-programacion-1.html` en el navegador y revisa la consola para ver el resultado.

## Estado

Ejercicio de práctica. Se conserva una estructura sencilla para facilitar el aprendizaje de JavaScript.
